## Meet Muse Image

Muse Image is an image model that reasons before it renders. Its low cost makes high-volume work viable at scale and its agentic image generation means you can create and edit complex images in a single model.

Priced for performance

Muse Image lets you run workloads that frontier pricing previously put out of reach. Ad variant generation, catalog imagery, and per-user personalization, all become viable at scale when images cost $0.01 each.

Agentic image generation

Instead of rendering a request straight away, Muse Image thinks about it first. It maps out a plan, pulls real references from the web, generates and runs code where precision matters and checks the result before returning it to you.

Output quality preservation

Generate from a description or edit what you already have. Muse Image is designed to change exactly what you specify and leave everything else untouched.
