key_logic_flow:
- PageAgent 是一个运行在网页客户端的 GUI Agent 框架，通过内嵌 JavaScript 脚本实现，无需浏览器扩展、Python 环境或无头浏览器。
- 核心原理是基于文本的 DOM 树操控，不依赖截图或多模态大模型，因此无需特殊权限即可运行。
- 用户可通过 CDN 脚本标签或 npm 包（page-agent）集成，并自由选择后端 LLM 模型（如 qwen3.5-plus）。
- 项目提供了可选的 Chrome 扩展以支持跨标签页的多页任务，以及处于 Beta 阶段的 MCP Server 供外部 Agent 客户端调用。
- PageAgent 的 DOM 处理组件和提示词借鉴了 browser-use 项目，并在 MIT 许可下发布。
- 适用的典型场景包括为 SaaS 产品添加 AI Copilot、智能表单填写、无障碍访问改造以及多页网页代理。

Add `?autoInit=false`

to load the script without creating the demo agent automatically. You can then instantiate it with `new window.PageAgent(...)`

.

`npm install page-agent`

```
import { PageAgent } from 'page-agent'
const agent = new PageAgent({
model: 'qwen3.5-plus',
baseURL: 'https://dashscope.aliyuncs.com/compatible-mode/v1',
apiKey: 'YOUR_API_KEY',
language: 'en-US',
})
await agent.execute('Click the login button')
```
