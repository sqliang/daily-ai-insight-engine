key_logic_flow:
- 用户输入视频主题或关键词，系统自动调用 LLM（支持 OpenAI、DeepSeek、Moonshot 等多种模型提供商）生成视频文案
- 根据文案内容从 Pexels 等无版权素材源检索匹配的高清视频片段，也可使用本地素材
- 通过 TTS 引擎（Edge TTS 或 faster-whisper）将文案合成为语音旁白，并同步生成字幕文件
- 使用 ffmpeg 和 ImageMagick 将文案、视频素材、语音、字幕和背景音乐合成为一个完整的高清短视频
- 支持竖屏 9:16（1080x1920）和横屏 16:9（1920x1080）两种分辨率，以及批量视频生成
- 提供基于 Streamlit 的 Web 界面和 FastAPI 驱动的 RESTful API 两种交互方式，支持 Docker 一键部署

通常情况下，ffmpeg 会被自动下载，并且会被自动检测到。 但是如果你的环境有问题，无法自动下载，可能会遇到如下错误：

```
RuntimeError: No ffmpeg exe could be found.
Install ffmpeg on your system, or set the IMAGEIO_FFMPEG_EXE environment variable.
```


此时你可以从 https://www.gyan.dev/ffmpeg/builds/ 下载ffmpeg，解压后，设置 `ffmpeg_path`

为你的实际安装路径即可。

```
[app]
# 请根据你的实际路径设置，注意 Windows 路径分隔符为 \\
ffmpeg_path = "C:\\Users\\harry\\Downloads\\ffmpeg.exe"
```

可以在ImageMagick的配置文件policy.xml中找到这些策略。
这个文件通常位于 /etc/ImageMagick-`X`

/ 或 ImageMagick 安装目录的类似位置。
修改包含`pattern="@"`

的条目，将`rights="none"`

更改为`rights="read|write"`

以允许对文件的读写操作。

这个问题是由于系统打开文件数限制导致的，可以通过修改系统的文件打开数限制来解决。

查看当前限制

`ulimit -n`

如果过低，可以调高一些，比如

`ulimit -n 10240`
