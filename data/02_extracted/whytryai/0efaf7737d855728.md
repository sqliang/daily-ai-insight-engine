## 👩💻 AI releases

**Alibaba**news:**Qwen3.8-Max**is a powerful multimodal model built for long, autonomous coding and professional tasks, with visual feedback and self-correction.**QwenWork**is an all-in-one work platform that handles tasks across cloud, desktop, and enterprise tools using AI agents.**Wan3.0**can turn any input, including documents, slides, spreadsheets, and web pages into 30-second continuous videos.

**Autodesk**launched**3D Editor + Canvas**in Flow Studio that let creators build and refine editable 3D scenes using image and video models right in the app.**Black Forest Labs**released**FLUX 3 Video**, which can generate 20-second HD clips with native audio and lip-synced dialogue in multiple languages.**ByteDance**launched**Seedance 2.5**, a video model that generates continuous 30-second clips in a single pass and can handle up to 50 reference inputs.**Genspark**open-sourced**GenOffice**, a free office suite for Mac, Windows, and Linux that works with docs, sheets, slides, etc., and comes with a built-in AI agent.**Google**news:**Ask Maps**can now find hotels, order food, and get real-time traffic info using a personal agent that connects to your Gmail and Calendar.**Gemini Spark**now integrates with Chrome and can automate web tasks like booking appointments, comparing products, and filling forms.

**HeyGen**launched a**Video Podcast**tool that turns documents and links into two-host video shows with B-roll footage, captions, and more.**Ideogram**launched**Object Remover**, which can erase selected items, logos, people, and text from images while preserving lighting and reflections.**Meta**launched**Muse Code**, a coding agent that can handle complex software engineering tasks, powered by the new**Muse Spark 1.2**model.**MiniMax**open-sourced**H3**, an omnimodal video model that generates 15-second 2K clips with native audio from any mix of images, text, and video inputs.**OpenAI**news:**Education Plugins**give educators and students bundled workflows to help with guided tutoring and lesson planning inside ChatGPT Work and Codex.**GPT-5.6 Sol**got a major accuracy upgrade (68% fewer factual errors) and a new reasoning slider for paid users.

**Perplexity**news:**Personal Computer**has rolled out to Windows, where it can complete multi-step tasks and control apps and files on your desktop.**Projects**(formerly**Spaces**) are shared hubs with persistent files and memory so teams and agents can carry context across tasks.
