key_logic_flow:
- Apple 发布了 Core AI 框架（Beta 版），这是一套专门用于在 Apple 硅片设备上运行 AI 模型的新框架。
- Core AI 支持在 CPU、GPU 和 Neural Engine 上运行推理，提供 Swift API 管理模型加载、推理执行和配置。
- Apple 同步推出了配套工具链，包括 Core AI Optimization 模型优化工具、Core AI PyTorch Extensions 模型转换工具和
  Core AI Debugger 可视化调试应用。
- Core AI 深度集成 Xcode 开发工具链，提供调试仪表、性能分析工具和 coreai-build 命令行编译工具。
- 该框架适用于神经网络类型的 AI 模型；非神经网络模型（如决策树）仍需使用 Core ML 框架。
- Core AI 最低部署目标为 iOS/iPadOS/macOS/tvOS/visionOS/watchOS 27.0+ 版本。
