## Cold start

Time to import Hono, register two routes, and exit. No HTTP server is started, so this isolates module resolution and initialization overhead.

## Install packages, fast

Install packages up to 40x faster than npm, with no extra tooling to set up.

$ ant i honoinstalled hono@latest1 package installed [155ms]

## From zero to a server

Write a handler, run the file. Ant serves a default fetch export, so real frameworks like Hono work with no adapter.

import { Hono } from 'hono' const app = new Hono() app.get('/', (c) => c.text('Hello from Ant')) export default app

$ ant server.js Listening on http://localhost:3000

## TypeScript, no build step

Run TypeScript directly. No tsconfig wrangling, no bundler, no dist folder.

the usual way

`$ tsc && node dist/app.js`

with Ant

`$ ant app.ts`

## Run code you don’t trust

Ant ships with a VM-isolated sandbox, not just a permission prompt. Mount your filesystem as read-only, open only the ports you name, and run untrusted JavaScript behind a hard boundary.

import { Sandbox } from 'ant:sandbox' const box = new Sandbox(({ mount: '.:/workspace' })) await box.run('untrusted.js') await box.close()

- Hardware-isolated
- Each sandbox is its own KVM / Hypervisor.framework VM.
- Read-only
- Mounts are immutable unless you grant write explicitly.
- No network
- Deny-all by default, forward only the ports you name.

## A registry for the ecosystem

Packages live on ants.land, the open registry for Ant. It speaks the npm protocol, so anything you publish installs by scope or bare name, with packages working right in your browser from esm.ants.land.

$ ant land login$ ant land publishpublished @you/thing@1.0.0
