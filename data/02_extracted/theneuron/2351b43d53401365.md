# 😼 Kimi K3 Shows Open Models Are Moving Upstairs

So there’s a new model from Chinese open weights AI company Moonshot that came out yesterday and it’s called Kimi K3. It arrived with 2.8 trillion parameters (the model's internal knobs for learning patterns), one million tokens of memory (roughly hundreds of thousands of words it can keep in view), and the *oh so subtle energy of a new neighbor parking a battleship in the driveway.*

**Here's what happened:**

Moonshot AI released Kimi K3, an open 3T-class model with native vision, a 1M-token context window, and full weights which are due to be released by July 27.

Open weights means the core model files can be downloaded, hosted, modified, and fine-tuned instead of only rented through an API.


Moonshot says K3 uses sparse experts (specialized sub-models that only partly activate for each task) to make a huge model cheaper to run than if every part switched on every time.

The early numbers are loud: K3 beat GPT-5.6 Sol on BrowseComp and Automation Bench in Moonshot's table, while Artificial Analysis said it used 21% fewer output tokens than Kimi K2.6.

The catch: Simon Willison found it capable but costly, with one SVG test burning more than 16,000 output tokens. Moonshot recommends 64 or more accelerators for serious deployment.


**How to try it:**

Use Kimi K3 on kimi.com, Kimi Code, or the Kimi API.

Watch for open weights by July 27 if your team wants to host or customize it.
