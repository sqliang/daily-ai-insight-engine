### What you'll learn

Map short-term, long-term, and episodic memory to concrete infrastructure decisions using cognitive science foundation

Build persistent cross-session memory with Amazon Bedrock and tools available in AWS Marketplace

Design episodic memory patterns for cross-session learning — agents that recall past interactions and outcomes without custom storage plumbing

Technical demos of memory tools from across the AI landscape, such as MongoDB Atlas and Redis Cloud — all available in AWS Marketplace
