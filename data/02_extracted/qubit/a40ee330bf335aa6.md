# 商汤大装置联合近20家生态伙伴发起“银河计划”，将共建5个万卡级国产智算集群

加速国产算力从落地可用到规模化盈利

7月18日，在WAIC 2026商汤科技 “基座大模型架构创新与生态合作论坛”上，商汤科技联合创始人、大装置事业群总裁杨帆发表《智变·共生——加速AI基础设施持续升级》主题演讲，系统呈现了商汤大装置国产AI基础设施“技术-生态-商业”闭环布局，分享国产算力规模化商用的技术突破与实践成果，并联合近20家生态伙伴发起“银河计划”，共启“国产AI基础设施规模化商用元年”。论坛上，商汤大装置与国星宇航达成太空算力战略合作，并联合上海人工智能实验室等五家顶尖科研机构启动“科学发现平台”战略合作，全方位拓展AI基础设施的能力边界与产业价值。

杨帆在演讲中表示，“十五五”开局之年，AI基础设施正迎来重要趋势性变革：Token市场爆发式增长、下游需求快速激增；国产芯片商业化快速成熟，以国产算力为核心的智算中心加速落地。在多重因素的共同促进下，国产AI基础设施规模化商用的窗口期已全面到来。

以国产化生态创新为核心，以区域布局和全球出海为路径，以端到端多模态产业应用为目标，商汤大装置持续推动AI基础设施从提供算力向创造产业价值升级。当前AI基础设施全面迈入Token时代，商汤大装置平台**日均Token服务量已达2.42万亿**，预计2026年**全年服务规模实现25倍增长**，并于**第四季度达到日均10万亿Token规模**，为Agentic时代提供坚实的基础设施支撑。

# 技术破局：同成本Token产出规模扩大2.5倍，加速国产算力规模化、可盈利

面对不断激发的AI生产力需求，商汤大装置以全链路技术创新，构建端到端的基础设施体系。针对当前国产算力规模化商用卡点，商汤大装置从“性价比、适配性、能效比”三个维度系统性破题，推动国产算力**从落地可用到规模化盈利**。

在性价比层面，依托异构混合推理技术，商汤大装置实现主流国产芯片MFU（Model FLOPs Utilization）提升85%~152%，**整体推理性价比达到NVIDIA H系列的1.25倍**；相比国产同构推理方案，**同成本下Token产出规模扩大2.5倍**。基于优化后的混推集群，可远超行业此前对国产算力“微利持平”的预期，实现从可用到可盈利。

在适配性层面，商汤大装置打造覆盖模型、框架、算子、工具链到硬件的全栈适配体系，实现模型高效迁移、多芯片快速适配与性能持续优化，大幅降低国产算力应用门槛。其中，AI4S长序列蛋白质预测场景通过融合算子优化，**整体预测耗时减少3倍**；AIGC视频生成场景下，**国产芯片运行DiT模型的多卡并行加速比达93%**；同时实现主流AI开发工具零成本迁移，开发者零学习成本即可完成国产芯片适配，打通国产芯片规模商用的落地路径。

在能效比层面，商汤大装置推出算电协同Agent，并重新定义TPW（Tokens Per Watt）作为AIDC全新价值标尺。依托八级数据穿透体系、五大智能决策链等，算电协同Agent能够实现算力资源调度、电价预测、储能充放电优化、Token产能优化等全流程智能决策，以“算力×电力×Agent”三位一体，实现**单位电力成本Token产出提升80%**、**平均电费单价低于同地区IDC 10%、算力负荷预测准确率达到96%**，开启AIDC系统级算效时代。

# 生态共筑：联合近20家伙伴启动“银河计划”，端到端释放国产算力价值

为加速国产算力从单点技术突破走向产业体系化繁荣，商汤大装置致力于推动构建覆盖智算中心、国产芯片、AI基础设施、模型应用等的国产化全产业链生态，凝聚国产AI基础设施生态合力，打通从底层技术创新到产业规模商用的全链路能力。

论坛上，商汤大装置**联合近20家生态伙伴发布国产AI基础设施生态共建“银河计划”**，涵盖寒武纪、沐曦股份、中科海光、华为昇腾、摩尔线程、曦望Sunrise、壁仞科技等头部国产芯片伙伴，曦智科技等核心零部件伙伴，以及硅基流动、趋境科技、中科加禾、清程极智、算丰信息、基流科技等基础设厂商。商汤大装置将依托该计划，与生态伙伴共同建设**1个Token运营中心，5个万卡级国产智算集群，**围绕**10个核心技术方向**开展联合创新，并**赋能200家AI初创组织**，推动技术、产业、资本深度融合，共筑开放繁荣的产业生态。

**“国产化并非单一的芯片替代，而是从芯片、零部件、基础设施到场景应用等整个中国创新能力的全链条协同。” **杨帆表示，商汤以贯穿多年的端到端能力为基础，从底层物理环境到软硬件协作，再到算电协同，目标就是让国产软硬件体系更快速地完成规模化、可盈利的市场化闭环，真正释放国产算力的价值潜力。

# 生态破界：前瞻布局光计算、量子计算、太空算力，支撑中国AI辐射全球

在持续引领智算发展的同时，**商汤大装置前瞻布局“光计算、量子计算、太空算力”三大新型计算路径**，携手产研伙伴，为下一代算力革命提前储备技术势能。在光计算方向，商汤大装置将探索光电互联、光子计算等关键技术，推动突破数据中心能耗与能效瓶颈；在量子计算方向，聚焦AI优化求解与前沿仿真实验等场景，加速新型计算范式与人工智能的融合创新。

**在太空算力方面，商汤科技与国星宇航达成战略合作**，宣布共建商汤算力星座，**星座规模预计将达到千星万P**，共同推动AI基础设施从地面万卡集群迈向在轨多星协同，构筑起全球化天地一体AI基础设施体系。**预计2026年，“商汤号”系列算力卫星将完成首发并组网；**到2030年，双方将建成由千颗级算力卫星、总算力超万P组成的“商汤太空算力星座”，形成覆盖全球的空间智能计算网络。

杨帆表示，“对于应急救灾、远洋船舶、野外作业等弱网络环境，太空算力能够有效填补地面网络覆盖的盲区。其价值不止于能力边界的突破，更是支撑中国AI能力向全球辐射的基础设施，有望大幅提高国产AI出海服务的覆盖率。”

# 商业创变：深化区域布局与场景深耕，推动“算力价值”向“产业价值”转化

依托全栈技术能力与生态体系，商汤大装置持续推进AI基础设施建设，从区域智算中心到城市级AI平台，再到海外国产算力集群，推动算力能力向多产业场景渗透，并以端到端多模态产业应用赋能区域AI创新发展。

在算力网络建设上，商汤大装置已在上海建成全国首个5A级智算样板，实现日均20万亿+Token服务能力，服务20+行业智能应用，并联合共建“空间智能+城市治理”数字化转型重点工程，形成产业转型的全国标杆；盐城作为区域节点，落地首个算电协同区域试点及异构Token工厂，首期建设3,000P算力规模，聚焦新能源、工业制造、低空经济等领域深化产业落地；在香港，商汤大装置正建设全港最大国产智算中心，2030年前目标达成40,000P算力规模。面向海外布局，将在沙特落地中国首个出海国产算力集群，输出AI基础设施中国方案。

在产业价值转化上，商汤大装置覆盖城市治理、具身智能、AIGC、AI for Science四大核心领域，并通过FDE（Forward Deployed Engineer）模式深入产业一线，加速AI在千行百业规模化落地。
