# 百度智能云与FluxA达成战略合作，共建 Agent 经济全球支付基础设施

诚邀30家OPC入驻内测

百度智能云与 FluxA 正式建立战略合作伙伴关系，共同探索 DAA（Daily Active Agents，日活跃智能体数）驱动下的新商业模式与数字基础设施建设。目前，百度Agent商业化产品已正式支持 Agent Payment，并与 FluxA 共建海外分销渠道。开发者可以基于百度智能云云市场构建可被Agent调用和购买的AI服务，并触达 FluxA 生态内的数万个 Agent。

# AI Agent 正在成为新的经济主体

随着 AI Agent 从信息获取工具逐步发展为能够自主完成任务并交付结果的执行主体，商业活动正在从人与人的交互，扩展至人与 Agent、Agent 与 Agent 之间的协作网络。百度创始人李彦宏在 2026 Create 大会上提出，AI 时代衡量生态价值的重要指标将是 DAA，即 Daily Active Agents。随着智能体数量持续增长，Agent 将逐步参与生产、协作、交易和服务交付等经济活动。

每一个 Agent 都需要身份、账户、支付和结算能力。而DAA时代 Agent 经济的持续发展，也将对新一代金融基础设施提出更高要求。

# FluxA 助力百度智能云打通Agent 自雇佣市场闭环

本次合作中，百度 Agent商业化产品已正式支持 Agent Payment，并与 FluxA 共建海外分销渠道。开发者可以基于百度智能云云市场平台构建 Agent商业化产品，并直接触达 FluxA 生态内的数万个 Agent。想上架服务、触达海外市场，百度提供市场资源、技术方案与分销渠道，FluxA Monetize 则作为全球化分销平台，构建海外货仓和A2A支付基建，承接海外用户与 AI Agent 的调用、交易、支付与结算需求。通过双方合作，Agent 的可交易资产、分销渠道与支付能力得以连接，进一步打通DAA生态从资产发行、能力交易到自动结算的完整商业链路。本次上线的百度智能云模型包，拷贝以下prompt给你的AI agent体验吧：

# FluxA打造面向 Agent 经济的支付底座

FluxA 是全球领先的 AI Agent 支付基础设施。传统支付平台服务于人的消费场景如扫码、输密码、等结算；而 Agent 经济的支付需求完全不同：毫秒级响应、毫厘级金额、全天候自动交易、跨境无障碍结算。面向这些全新场景，FluxA 从底层重新设计了一套 AI 友好的支付与交易能力：

低费率的高频微交易，让毫秒级的小额支付成为可能；Financial Harness 机制，确保 Agent 在授权范围内安全自主地交易；全球收款与即时清结算，打破跨境协作的金融壁垒；一键启用的 Token Paywall，支持基于 Token 充值、计量和结算的支付模式。

目前，已有超过 9 万个 Agent 正在使用 FluxA 钱包，超过 1 万个 AI Agent 资源在 FluxA Monetize 平台上完成商业化，接入 FluxA 生态的应用，都可以快速触达数万个 AI Agent。
