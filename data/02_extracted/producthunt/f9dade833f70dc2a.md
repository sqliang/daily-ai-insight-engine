#### What's great

free tools (2)completely free (3)great coding agent (2)handles large projects (1)

I'm an academic who also codes, so my daily usage is messier than a pure developer's: prototyping code, rearranging project files, revising parts of an academic paper, and occasionally asking it to diagnose something weird on my laptop. Freebuff handles that mixed workflow well. I've used the web app, the CLI, and the desktop app, and for real work I'd rank them desktop first, CLI second, web last. The desktop app working directly with my file system is a big deal for me. Even with my country sitting in the restricted access mode, it has quietly replaced several paid AI subscriptions I used to maintain.

#### What needs improvement

more coding sessions (1)better long-session ui (1)

A mobile companion app that can monitor or continue a desktop session remotely. Some newer coding agents already do this, and for now I get by with a remote desktop workaround, which is functional but clunky. More coding sessions for restricted regions would also help. On larger tasks I'd like an explicit implementation plan to approve before the agent starts writing code.
