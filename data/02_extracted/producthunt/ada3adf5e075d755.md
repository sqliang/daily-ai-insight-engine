# BearDrive

Product Hunt product page for BearDrive.

Tagline: The open-source shared folder for your team's AI agents

Description: Your AI agents create real files locally: reports, decks, CSVs, research. BearDrive syncs the folder they already work in, so every file is born shared: versioned, attributed down to the agent session, with links only your team can open. Unlike Notion or Drive, nobody moves anything; a teammate's agent reads your agent's work at a real local path seconds later. Works with Claude Code, Cowork, Codex, Gemini CLI, any local tool. Open source and self-hostable. Managed service free during beta.
