key_logic_flow:
- Flipper One 是一款正在开发中的多功能硬件设备，官方声明最终规格可能调整，当前重量和电池容量尚未最终确定
- 采用 Rockchip RK3576 八核 CPU（4×Cortex-A72 + 4×Cortex-A53，最高 2.2GHz）作为主处理器，集成 Mali-G52
  MC3 GPU 和 6 TOPS NPU，搭配 Raspberry Pi RP2350B 双核 Cortex-M33 + 双核 RISC-V 低功耗 MCU
- 配备 8GB LPDDR5 运行内存、64GB UFS 2.2 内部存储、24000mWh（约 7000mAh）电池，支持 USB PD 快充协议最高 26V
  输入
- 提供丰富的物理接口：两个 USB 3.1 Type-C（其中一个支持 DisplayPort Alt Mode）、一个 USB 3.1 Type-A、全尺寸 HDMI
  2.1（4K@120Hz）、双千兆 RJ45 网口、3.5mm TRRS 音频孔、MicroSD 卡槽和 Nano SIM 卡槽
- 设备背板设有 M.2 Key B 扩展端口（支持 2242/3042/3052 规格），可扩展 PCIe 2.1 x1、USB 3.1、SATA3 及 SIM
  卡直通等，对外提供 GPIO 排针和 Debug 调试接口
- 无线通信采用 MediaTek MT7921AUN 方案，支持 Wi-Fi 6 三频（2.4/5/6GHz）2×2 MIMO 和蓝牙 5.2
