key_logic_flow:
- Ox Alpha 是一款由匿名第三方提供商量身打造的隐形模型，OpenRouter 仅负责转发请求，并不拥有或运营该模型。
- 该模型定位为推理模型，适用于编程、长周期智能体任务以及结合文本与视觉内容的生产负载，提供 1M 上下文窗口。
- 模型于 2026 年 8 月 20 日发布，当前输入与输出每百万 token 的价格均为零，处于免费阶段。
- 性能方面，其吞吐量为 33 tok/s、延迟 3.76 秒、3 天正常运行率为 99.99%，工具调用错误率约 3.46%。
- OpenRouter 显示 Claude Code、Hermes Agent、Oh-My-Pi 等应用向该模型发送了大量流量，提示其真实生产使用场景以智能体编程为主。
- 该模型支持 OpenAI 兼容 API 与流式输出，可通过 reasoning 参数启用内部推理过程并在响应中返回 reasoning_details。

## About Ox Alpha

OpenRouter makes Ox Alpha by Stealth available through a unified, OpenAI-compatible API using the model ID stealth/ox-alpha. It is served by Stealth.

Ox Alpha accepts text, images and video and returns text. It has a 1,048,576-token context window and a maximum output of 131,072 tokens.

It was released on August 20, 2026.

## Frequently asked questions

### What is Ox Alpha?

Ox Alpha is a reasoning model designed for coding, sustained agentic work, and production workloads. It is suited for long-horizon software engineering, complex reasoning, and workflows that combine text with visual context. Ox Alpha is a stealth model. It is developed and operated by a third-party provider who has chosen to remain anonymous during this preview.

### Is Ox Alpha free?

Yes. The pricing shown on this page for Ox Alpha is zero, so you are not charged for prompt or completion tokens.

### What is the context length of Ox Alpha?

Ox Alpha has a 1,048,576 token context window. It supports up to 131,072 completion tokens.

### Does Ox Alpha support tool calling and structured outputs?

Yes. Ox Alpha accepts `tools` and `tool_choice` for function calling. It supports `response_format` for JSON output, without JSON-schema enforcement.

### What inputs and outputs does Ox Alpha support?

Ox Alpha accepts text, images and video as input and returns text.
