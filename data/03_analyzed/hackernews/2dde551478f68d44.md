key_logic_flow:
- Sem 在 Git 之上提供语义理解能力，将代码变更按函数实体而非行号进行展示。
- 该工具支持 diff、blame、impact 和 log 四种操作，全部基于函数层面进行语义分析。
- Sem 能够识别代码库中函数的三种变更类型：新增（added）、修改（modified）和删除（deleted）。
- 传统 Git diff 按行展示变更，而 Sem 将其聚合为函数级别的实体变更，让开发者看到代码变更的实际语义。
