推出 ChatGPT Work：ChatGPT 中的一个智能体，帮助你承担更有雄心的任务。它可以从你的应用和工作流中收集信息，创建表格、幻灯片、文档和 Web 应用等成品材料；也可以将复杂项目拆解为更小步骤并独立完成，持续处理数小时。

内置 Codex 技术后，ChatGPT 现在可以超越回答问题，在网页、移动端和桌面端完成真正的工作。每周有超过 500 万人使用 Codex。尽管它最初是面向开发者的编码智能体，如今已有超过 100 万人将其用于软件开发之外的工作，显示出它的能力可以支持更广泛的任务。

为了更好地管理这些任务，ChatGPT Work 由我们最新的前沿模型 GPT‑5.6 提供支持，该模型也于今天正式全面推出。GPT‑5.6 让 ChatGPT 在多步骤任务推理以及按照你的模板和参考文件创建材料方面达到业界领先水平。

学习使用 ChatGPT Work 的最佳方式，是交给它一个你已经很熟悉的任务：分析月末预算差异、把源材料转化为营销活动简报，或准备销售会议。你可以跟进它的进展、回答问题、改变方向，并批准重要操作。

你甚至可以用一个请求让 ChatGPT Work 接手整个工作流。例如，它可以把客户研究转化为营销活动简报，再用该简报创建营销素材，并在每一步都保留上下文的同时，为不同市场调整这些素材。

即使你离开电脑或手机，ChatGPT Work 也能通过定时任务持续推进项目。例如，它可以独立地将 Microsoft Teams 和 Slack 的新消息转化为更新后的文档或幻灯片，然后与团队分享重要变更。

在早期测试中，我们已经看到 ChatGPT Work 如何拓展用户的能力：

OpenAI 内部近 100% 的团队，包括财务和销售团队，现在都使用 ChatGPT Work 和 Codex 来加快进展、承担更困难的任务，并把更多时间用于客户。

- 在销售场景中，ChatGPT Work 可在 24 小时内将一次发现式对话转化为针对关键任务问题量身定制的概念验证，而这一流程通常需要数周。ChatGPT 整理笔记，将请求分派给解决方案架构师，并与技术团队协作，让负责人能够专注于客户，并作为高价值的顾问型伙伴提供服务。
- 在财务场景中，ChatGPT Work 帮助团队查找源数据、将其移入 Excel 或 Sheets、进行核对、创建幻灯片并验证结果，把月末结账和预测从数天缩短到数小时。这让财务团队有更多时间了解预测中发生了什么变化、解释变化原因，并就公司下一步该怎么做向领导层提供建议。

ChatGPT Work 今天起在 ChatGPT 网页端和移动端面向 Pro、Enterprise 和 Edu 提供，Plus 和 Business 将在未来几天推出。在 ChatGPT 桌面应用中，聊天、“工作”(Work) 和 Codex 面向所有套餐开放，包括免费套餐；该应用现已在全球提供 Windows 和 Mac 版本下载。

有了 ChatGPT Work，无论你在哪里，工作都能持续推进。你可以让它从手机上启动任务，在路上审阅草稿，或在会议间隙查看较长工作流的状态。回到办公桌前时，你可以在网页端继续处理同一项工作。

为了带来更强大的体验，ChatGPT 桌面应用现在可以做得更多。在桌面端，ChatGPT 可以使用你的本地文件和应用来完成工作。对于基于网页的工作，ChatGPT 新增的内置浏览器可将网站、工具和在线文件整合进来，让你在一个地方推进工作。

从今天起，Codex 应用将并入新的 ChatGPT 桌面应用。Codex 仍是面向开发者和技术专业人士的强大编码智能体，并在核心工作流中加入了新功能，包括在差异中进行行内编辑、在侧边面板审阅 Pull Request、更快的计算机使用能力（由 GPT‑5.6 提供支持），以及在单个项目中支持多个代码库。

要开始使用 ChatGPT Work，请通过插件连接你已经开展工作的工具和上下文。

插件可将 ChatGPT 连接到 Slack 和 Microsoft Teams、Google Drive 和 SharePoint、电子邮件、日历、CRM、项目跟踪器以及其他内部工具等应用和系统。ChatGPT 会根据你的提示自动判断何时引用插件；你也可以在提示中输入“@”后接应用名称，指示 ChatGPT 从特定应用提取上下文。新的统一插件目录将插件集中到一处，ChatGPT 还可以在对话中推荐相关插件。

连接应用和工具后，ChatGPT 可以理解你要完成的目标，从相关来源提取信息，创建文档、演示文稿和分析，并在你保持掌控的同时在后台持续完善草稿。

我们还将在 ChatGPT 中以公开测试版推出站点 (Sites) 功能。借助站点，你可以把工作成果或想法转化为互动站点或 Web 应用，并通过 URL 分享给团队或公开发布。当你想创建实时仪表板、项目跟踪器、发布日历、原型、内部门户和交互式报告等内容时，站点会很有用。你可以直接在 ChatGPT 中测试自己构建的站点，也可以为项目引入最新的网页上下文。当底层信息发生变化时，ChatGPT 也可以更新这些站点。

ChatGPT Work 可以帮你接手重复性任务，让你腾出时间投入更有影响力的工作。

定时任务让你可以要求 ChatGPT 执行一次操作、按计划或在事件发生时重复执行，或持续监控变化。

定时任务可以使用你已连接的应用和浏览器来：

- 每周审阅新的 Slack 更新，并刷新周期性会议议程。
- 每天早上检查网站和仪表板，总结变化并发送报告。
- 监控新的客户反馈，并将反复出现的主题转化为按优先级排列的产品想法。
- 当通过电子邮件收到新反馈时更新演示文稿。

你始终掌控 ChatGPT 与你协作的方式。由你决定它可以访问什么、何时向你确认，以及何时需要你的批准才能采取行动。随着优先事项变化，你可以审阅进度并引导工作方向。

在桌面端，ChatGPT 现在包含内置浏览器，帮助你在一个地方收集在线信息、使用网页工具，并完善基于网页的工作。

你可以让 ChatGPT 研究市场、比较来源、从网站提取信息，或在应用内打开并完善 Google Workspace 和 Microsoft 365 中的文件。它可以使用浏览器引入最新上下文、在网页间执行步骤，并在你审阅和指导结果的同时持续推进工作。

在桌面端，“计算机使用”让 ChatGPT 代表你使用计算机，在你的应用、工具和浏览器中后台执行任务，包括点击、输入，以及把文件移动到需要的位置。你可以将它用于一次性任务；当周期性工作包含电脑上的操作步骤时，也可以将其作为定时任务的一部分。

我们还在更新 Chrome 扩展，让用户可以直接在 Chrome 侧边栏中使用 ChatGPT。这些能力建立在我们从 Atlas 以及用户那里获得的经验之上，他们帮助我们理解智能体式工具如何让基于浏览器的工作更有用。我们将开始逐步停用独立的 Atlas 浏览器，并会向用户分享如何迁移到 ChatGPT 的相关信息。
