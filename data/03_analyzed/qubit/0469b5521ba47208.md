# 趋境科技华东区域总部落地钱江世纪城，五年内建成万卡级高品质 AI Token 工厂

推进华东区域业务布局的重要一步

7月21日下午，北京趋境科技有限责任公司与萧山区钱江世纪城签署产业投资合作协议，**趋境科技华东区域总部项目正式落地钱江世纪城。**

杭州市委常委、萧山区委书记孙旭东，趋境科技首席科学家武永卫教授出席并见签。萧山区领导朱国军、钱江世纪城党工委书记张文波、趋境科技发起人章明星教授及总裁兼 CFO 武文洁博士参加。

**此次签约是趋境科技推进华东区域业务布局的重要一步。**根据协议，趋境科技将在钱江世纪城重点**建设高效能人工智能 Token 生产服务平台（ATaaS）华东区域交付与服务中心**，围绕企业级人工智能推理需求，持续完善区域交付与服务能力。

按照项目规划，趋境科技力争在**五年内建成万卡级集群规模的高品质 **AI Token** 工厂**，打造具有区域示范意义的 AI Token 服务载体，为企业客户人工智能应用的落地与规模化部署提供支持。

作为全球领先的高效能 AI Token 生产服务商，趋境科技源自清华大学计算机系高性能计算研究所技术成果转化，专注于企业级全场景专属推理解决方案。公司核心团队为开源项目 KTransformers 和 Mooncake 创始团队，在大模型推理系统、软硬件协同优化等方向具备持续的技术积累。

华东区域总部落地后，趋境科技将依托杭州人工智能产业生态及钱江世纪城的区位与产业基础，稳步推进 ATaaS 平台的区域建设和服务落地，进一步提升面向华东地区企业客户的交付响应与技术服务能力。

在规模化 AI Token 生产实践中，趋境科技持续积累工程交付经验。自2026年春节以来，公司平均单台设备的 AI Token 生产效率提升3倍以上，高品质 AI Token 总产能增长超过30倍；其中，服务某头部万亿参数大模型的项目，**日均高品质 AI Token 产量已稳定达到万亿量级。**

上述增长并非单纯依靠扩大硬件规模，而是通过模型适配、推理执行、KV Cache 管理、存储与网络协同、服务运维等环节的系统优化实现。面向真实生产环境中的成本、效率与稳定性要求**，趋境科技坚持“少模型、深优化”的技术路线**，建立贯穿高品质 AI Token 工厂设计、建设、生产和运营的全流程工作体系，并已在既有项目中完成规模化投产验证。相关技术与项目经验将应用于华东区域交付与服务中心建设，进一步提升区域项目实施及长期服务能力。
