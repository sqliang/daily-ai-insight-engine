# 《时代》周刊全球AI 100放榜，精准捕获稚晖君最“想低调”的幕后老板

久久不愿来到台前的智元掌舵人

衡宇 发自 凹非寺

量子位 | 公众号 QbitAI


时代周刊刚刚公布了**2026年度全球百名AI人物**名单——

奥特曼、马斯克、Ilya、李飞飞、LeCun、Dario等全球AI行业的Big Name悉数入选。

国内的熟悉面孔同样不少，字节跳动梁汝波、阿里巴巴吴泳铭、月之暗面杨植麟、智谱张鹏、Manus肖弘、上海AI Lab周伯文等也在名单之列。

在这份名单的“Innovators”一栏里，还有一个对更广泛公众而言并不算眼熟的名字。

**邓泰华**。

很多人不知道这个首次上榜的人是谁。

国内具身领域最万众瞩目（之一）**智元的创始人、董事长兼CEO，也是更广为人知的“稚晖君”**（彭志辉）**的顶头老板。**

他在华为工作逾二十年，长期主政无线与计算两大核心业务，曾推进鲲鹏与昇腾生态。

后来AI领域风云再起，他离职创业，这才有了智元。

然而**在更广泛的公众视野里，智元后相当长的一段时间内，几乎完全与稚晖君的技术名片和个人IP绑定在一起。**

智元创立初期，邓泰华不无狡黠地选择隐于幕后，任由稚晖君站在镁光灯的最中央。

**直到去年**，随着智元启动大规模商业化扩张与资本动作，邓泰华的名字才开始集中对外曝光，出现在工商变更、合作伙伴大会以及资本市场的核心新闻之中。

# 邓泰华是谁

邓泰华，1977年生人。

1995年，他进入**电子科技大学**信息与通信工程学院计算机通信专业学习。

**本科毕业后邓泰华就加入了华为，此后在华为工作逾20年。**

他的早期职业核心在华为的无线网络/移动通信体系，也就是基站、运营商网络和移动宽带基础设施业务。

2017年以前，邓泰华的公开title包括华为无线网络业务部TD-LTE、TD-SCDMA、WiMAX产品线总裁，TDD产品线总裁，无线解决方案部部长，东北欧地区部副总裁等。

通信技术与标准→产品线经营→海外区域销售和交付→大型客户与生态合作，可以说这一阶段，邓泰华已经经历了华为运营商业务的典型完整链条。

2017年起，邓泰华开始以华为无线网络产品线总裁身份出席全球移动宽带论坛等公开活动。

该岗位对应的业务是华为核心运营商基础设施业务之一，技术领域包含4G、5G、TDD/FDD制式下的无线网络整体解决方案。

2019年11月前后，邓在华为的头衔转为华为高级副总裁。

**2020年，其对外title又新增了计算产品线一把手，全面掌舵鲲鹏通用算力、昇腾AI芯片的产业生态建设。**

2022年11月初，邓泰华最后一次公开以该身份出席华为全联接大会演讲。

至于邓泰华是什么时候从华为离开的，外界不得而知。

**同年12月底，任职于华为计算产品线昇腾部门的主任工程师稚晖君于B站宣布已于华为离职。**

一位接近智元的知情人士向量子位透露，早于这个时候，邓泰华、稚晖君在内的一只不足10人的小团队，已确定创业机器人赛道。

后来《科创板日报》的相关报道显示，正是邓泰华邀请当时还在华为工作的稚晖君创业。

次年2月，智元机器人主体公司完成工商注册，智元正式诞生。

# “低调”邓泰华

**彼时，在普罗大众眼里，只知B站百大UP主稚晖君跨界创业，不知幕后操盘手邓泰华。**

但这丝毫不影响智元机器人在一级市场的抢手程度。

成立仅一个月，智元就公开了获得的天使轮投资，资方为高瓴创投、奇绩创坛。

成立不到半年，智元估值突破10亿美元，成为全球最快成长的具身智能独角兽；到2023年年底，智元已经一路融到了A+++轮，该轮融资6亿元人民币。

**不过在2024年一整年，智元的融资进展仍然一直在A轮的各种“+”里打转**——哪怕2024年1月智元制造工厂已经落地，8月公司机器人产品线远征系列推出了第二代、同场发布第二条机器人产品线灵犀系列。

事情的转机发生在2025年3月。

如果智元过几十年（maybe过个十几年？几年？又或许人家压根不出）出一本《智元往事：快的胜利》或《造一家能做具身智能的公司》之类的兼顾技术、创业史、组织管理的公司编年体传记，一定也会在这个时间点不吝笔墨。

**这个月，智元机器人的法定代表人变更为邓泰华。**

也正是在这一时间节点，邓泰华**结束了创业初期低调幕后的状态**，正式走向台前，以智元董事长兼 CEO 的身份出现在公众报道当中。

《中国经营报》的报道则显示，智元机器人内部人士确认，邓泰华实际上一直担任该公司的创始人、董事长及首席执行官。

只是过去他一直保持低调。


更重要的是，**这一个月，智元宣布了腾讯领投的B轮融资，投后估值150亿元人民币。**

后来稚晖君在接受《澎湃新闻》采访时表示，自己主攻产品、技术与团队管理，邓泰华负责战略方向和商业布局。

2025年8月，在智元第一届合作伙伴大会上，邓泰华完成了创业后的**首次公开露面**。

但低调的他一如既往地低调。

虽然这次大会智元邀请了不少媒体到场，但媒体无法进入会场现场，只能挤在大会举办地的另一个小会议厅通过分辨率模糊的在线直播一睹邓泰华的创业后首秀。

并且，演讲进行中途，智元掐断了媒体间的直播信号——因为后面的内容是一段29分钟的闭门内容，“不便对外”。

外界还有一个感知：也是从去年年中开始，稚晖君个人IP的在智元对外宣传中的声量、频率都开始降低。

而等到邓泰华的**第二次公开亮相，时间已经来到了一年之后。**

今年4月，智元举行了第二届合作伙伴大会。邓泰华罕见亮相作了近两小时演讲。

演讲中，他披露公司在2025年营收突破10亿，年增速接近20倍；还宣布了智元的“358宏图”营收规划，即：

**3年目标**（截至2025年）：营收突破10亿元（已经完成）**5年目标**（2027年）：营收达到100亿元**8年目标**（2030年）：营收冲刺1000亿元，实现大规模产业爆发

第二届合作伙伴大会结束后，邓泰华意料之内地又消失了。

直到**7月底，智元官方对外确认正式启动赴港IPO流程**，邓泰华也如以往那样低调隐身。尽管具身智能浪潮迭起，他的身影也没出现在任何对外活动上。

更别提接受媒体采访了。

BTW，4月开大会的时候，稚晖君就已经透出口风，“我们已经交表了”。

# 其实他并无法低调

颇为值得玩味的一点在于，**邓泰华并非不具备对外表达的能力及经验**。

在华为任职期间，尽管同样极少接受媒体深度专访，但少量各种行业会议的会后简短群访、媒体问答中，仍然可见邓的身影。

公开资料显示，至少从2017年起，他就多次在国际运营商大会、全球论坛、产业峰会、行业论坛中演讲。

调任计算产品线总裁后到离职华为前的这段时间里，邓泰华公开演讲尤其频繁。

他连续三年登上华为全联接大会主舞台，主导鲲鹏、昇腾、欧拉等重大生态发布，并频繁出席各地政企算力产业论坛，面向运营商、产业伙伴输出算力生态建设思路，对于宏大的技术叙事与生态布局早已驾轻就熟。

**镜头、话筒和大场面，都不曾成为邓泰华面临聚光灯的障碍。**
