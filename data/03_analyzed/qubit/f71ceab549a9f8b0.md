# AI步入“自我进化”时代，李彦宏首提AI时代度量衡“DAA”｜Create2026百度AI开发者⼤会速览

李彦宏提出“AI时代进化论”

允中 发自 凹非寺

量子位 | 公众号 QbitAI


龙虾的出现，引爆了智能体赛道。

对应移动互联网最通用的度量衡“日活用户数”（DAU），刚刚，AI智能体时代另一个度量衡出现了——

**日活智能体数（DAA）**。

刚刚，Create2026百度AI开发者⼤会在京召开。

百度创始人李彦宏首次提出DAA，在他看来，Token不一定代表终局，它只代表成本并不代表收益，衡量的是投入而非产出。

而DAA这个指标，更为关注的是有多少Agent在给人类干活，并交付结果。李彦宏预测，未来全球日活智能体数（DAA）可能会超过100亿。

与此同时，大会以“自我进化”为主题，展示了百度一系列AI布局及其进展。

李彦宏也解释了自我进化的三层涵义：

一是智能体的自我进化，从被动响应到从环境中不断吸取营养来提升自己，并主动执行；

二是人类个体的自我进化，从普通个体到超级个体，并学会跟AI共存；

三是企业组织的自我进化，从人与人的分工协作，到人与智能体的混合编队，成为超级组织。


而为了支撑智能体应用爆发，百度构建起了“芯云模体”全栈能力。

具体都有哪些进展，我们一一来看。

# 百度搭子DuMate正式亮相

大会上，百度搭子DuMate全新推出移动端App，一句话，实现从“想法”到“结果”自动执行。

DuMate自MVP版本发布以来快速迭代，使用场景不断扩大，任务完成率不断提高，现在已可以胜任多种复杂工作。

其将百度AI搜索、秒哒、伐谋、百科等核心产品能力集成为可随时调用的内置技能，同时强化长程任务执行与主动决策能力，正逐步成为用户进入Agent世界的统一入口。

目前，DuMate已在多个国际权威Agent Benchmark评测中达到SOTA水平。

据悉，Dumate移动端App实现了与PC端的远程实时互通，可随时随地发起任务，真正实现7×24小时AI助手陪伴，PC端与移动端数据、任务状态实时同步，无缝切换。

# 秒哒App及企业版上线

另外，百度发布代码智能体秒哒App及企业版。

李彦宏表示，秒哒这样的代码智能体，让软件行业正被重新定义，‘一次性软件’或者说‘日抛型软件’变得合理，“这个市场很可能会被放大10倍。”

据悉，秒哒App本身90%的代码由秒哒智能体自动生成。截止目前，秒哒生成的应用已累计服务用户超1000万，应用价值达50亿元。

# 慧播星升级为“百度一镜”

现场，百度慧播星升级为“百度一镜”，成为全球首个全场景多智能体数字人平台。

从主要应用于直播带货场景的数字人，升级为以数字人为特色，包含直播、视频、实时互动等多形态的“全场景数字人平台”，并可生成几分钟乃至数小时的高互动内容。

李彦宏表示，“数字人就是‘看得见’的智能体”，未来很多场景下，人们调用智能体、管理任务、获得服务，很可能不是面对一个聊天框，而是面对一个数字人。

一镜海外版同步推出，让全球创作者能更高效地做出有质量、有商业价值的内容。

# 百度伐谋2.0发布

与此同时，自我演化决策智能体百度伐谋升级至2.0版本，进一步直接面向业务专家，聚焦生产排程、物流规划、工艺优化三大场景。

百度伐谋2.0让业务专家无需懂代码，可像带徒弟一样通过对话进行调整；企业级记忆系统将业务逻辑沉淀为可复用的AI资产，越用越懂企业，方案持续优化。

百度伐谋在三大典型行业场景实现垂直能力的突破：

- 生产排程领域，将404个任务分配到82台注塑机，生产率提升6.31%；
- 物流规划领域，在自动化码头，帮助全球首套码头智能管控系统A-TOS实现10.21%的绝对指标提升，助力中国产品走向世界；
- 工艺优化方面，强化跨学科知识融合建模能力，在科学计算模型保障下理解材料、化工、生物等原理。

此前，百度伐谋Agent 2.0已登顶机器学习权威基准MLE-Bench，在15道最难题目中拿下9项第一，超越搭载Claude-Opus-4.6等主流大模型的同类智能体。

# 百度智能云

5月13日，在Create 2026百度AI开发者大会上，百度集团执行副总裁、百度智能云事业群总裁沈抖披露了一系列最新进展。

首先，百度智能云**去年成功支持了超过2000万辆L2级辅助驾驶新车交付**。

沈抖介绍，百度智能云通过芯云模体新全栈AI云，目前支持涵盖主机厂、电池、芯片、无人车等产业链领军企业的研发、训练、仿真、测试和量产交付多个环节，客户包括吉利、理想、长安、蔚来、地平线、新石器、宁德时代等。

其次，百度智能云目前**已服务超过1000家AI硬件公司**，为其提供核心算力、模型服务、Agent Harness等能力。

客户覆盖范围包括全球排名前十的手机厂商、中国排名前十AI眼镜企业中的90%、Top5扫地机器人品牌，以及Top5 AI玩具厂商，另有500万台智能家电已接入百度智能云。

第三，百度智能云**已服务超30家重点具身智能企业**，市场份额超过第二、第三名总和。

当前，具身智能大规模落地，正在攀登“数据、模型、本体”三座大山。

在数据层面，百度智能云正将十余年自动驾驶积累的数据服务能力迁移至具身场景，支持大规模数据采集与标注。在模型训练方面，依托百度智能云在大模型AI Infra领域的长期积累，目前典型VLA训练已实现超过70%的训练加速，世界模型推理时延降低近50%，原本按周进行的训练周期，正在缩短至按天迭代。

目前，百度智能云已形成覆盖算力、平台工具链、数据服务、语音交互、安全能力在内的全栈支撑体系，并将推出“训练-评测-反馈”闭环系统，进一步帮助具身智能企业实现模型规模化训练与持续进化。

除此之外，百度智能云公布以昆仑芯为主的国产算力在金融行业的规模化落地情况。

其中，招商银行基于昆仑芯P800打造国产算力底座，在目前已上线超800个AI智能体应用，覆盖风控、营销、研发、办公等核心场景，其中超50%运行于昆仑芯算力之上。

浦发银行则基于昆仑芯精调金融分析专精模型，在多个场景提升金融意图识别准确率，其2025年资产总额突破10万亿元，对公贷款尽调效率显著提升。目前，全国100%系统重要性银行及800余家金融机构已选择百度智能云。

百度智能云还宣布全面升级Agent基础设施，将MaaS模型服务升级为Token Factory（词元工厂），并发布Harness Engineering（驾驭工程），帮助企业和超级个体打造和使用智能水平更高、更能交付结果的智能体。

其中，Token Factory以Agent-first理念，大幅减少token重复计算，推理速度较市场平均水平提升约25%，并依托百度自研昆仑芯片，为文心、DeepSeek、GLM、MiniMax等国产主流大模型提供更高性价比的算力支撑。
