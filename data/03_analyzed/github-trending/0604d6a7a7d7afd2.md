key_logic_flow:
- 用户输入视频主题或关键词，系统自动调用 LLM（支持 OpenAI、DeepSeek、Moonshot 等多种模型提供商）生成视频文案
- 根据文案内容从 Pexels 等无版权素材源检索匹配的高清视频片段，也可使用本地素材
- 通过 TTS 引擎（Edge TTS 或 faster-whisper）将文案合成为语音旁白，并同步生成字幕文件
- 使用 ffmpeg 和 ImageMagick 将文案、视频素材、语音、字幕和背景音乐合成为一个完整的高清短视频
- 支持竖屏 9:16（1080x1920）和横屏 16:9（1920x1080）两种分辨率，以及批量视频生成
- 提供基于 Streamlit 的 Web 界面和 FastAPI 驱动的 RESTful API 两种交互方式，支持 Docker 一键部署
