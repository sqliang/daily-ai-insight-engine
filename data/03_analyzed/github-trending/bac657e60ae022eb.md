key_logic_flow:
- JuliusBrussee/caveman 是一个 AI 代理输出压缩技能，通过让代理以简洁的"穴居人"风格回复来减少约 75% 的输出 token，同时保持
  100% 的技术准确性。
- 该技能支持 lite（去填充词）、full（默认穴居人）、ultra（电报风格）和 wenyan（文言文）四种压缩级别，用户可通过一条命令切换。
- 安装方式为单行命令（curl 或 PowerShell），需要 Node.js ≥18，可安全重复运行，自动检测已安装的代理并跳过缺失的代理。
- 项目在 10 个编程任务上实测平均输出 token 减少 65%，其中解释 React 重渲染错误等任务节省高达 87%，重构 callback 等任务节省 22%。
- 配套工具生态包括 caveman-code（完整终端代理）、cavemem（跨代理记忆）、cavekit（规范驱动构建循环）和 cavegemma（基于 Gemma
  4 31B 的微调模型）。
- caveman 还隶属于 JuliusBrussee/skills 技能合集，该合集包含 caveman、grill-me、interface-kit、junior-to-senior
  和 loop-factory 共五个技能，可通过 npx 单命令安装。
