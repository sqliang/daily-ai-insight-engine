key_logic_flow:
- OpenMed 是一个开源的临床自然语言处理工具包，提供医学实体识别、PII 脱敏和临床文本结构化功能，只需一行 Python 代码即可调用。
- 该项目包含超过 1000 个专门针对生物医学领域的 NER 模型，涵盖疾病、药物、解剖学、基因等多个实体类型，并支持 12 种语言和 247 个 PII 检查点。
- OpenMed 完全在本地设备上运行，支持 CPU、CUDA 和 Apple MLX 加速，在 Apple Silicon 上推理速度可达 CPU PyTorch
  的 24 到 33 倍。
- 开发者可通过 Python API、Docker FastAPI REST 服务或 Swift SDK（OpenMedKit）在各自平台集成，OpenMedKit
  支持 iPhone、iPad 和 Mac 上的完全离线推理。
- 该项目使用 OpenAI 的 Privacy Filter 稀疏 MoE 变压器架构，并提供了三个模型变体：OpenAI 原始版本、Nemotron-PII 微调版本和
  OpenMed 多语言版本。
- OpenMed 以 Apache-2.0 许可证发布，支持离线或气隙环境部署，可指定本地模型路径避免连接 Hugging Face Hub。

from openmed import extract_pii, deidentify
text = "Patient: John Doe, DOB: 01/15/1970, SSN: 123-45-6789"
# Extract PII with smart merging (prevents tokenization fragmentation)
result = extract_pii(text, model_name="pii_superclinical_large", use_smart_merging=True)
# De-identify with the method you need
deidentify(text, method="mask") # [NAME], [DATE]
deidentify(text, method="replace") # Faker-backed, locale-aware, format-preserving fakes
deidentify(text, method="hash") # Cryptographic hashing
deidentify(text, method="shift_dates", date_shift_days=180)
```
