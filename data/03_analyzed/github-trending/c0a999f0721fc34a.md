key_logic_flow:
- Hyper-Extract 是一个基于 LLM 的知识提取与演化框架，可将非结构化文本自动转化为强类型知识摘要，支持增量式知识库扩展。
- 该工具采用三层架构设计：Auto-Types 提供 8 种强类型数据结构（Model、List、Set、Graph、Hypergraph 等），Methods
  实现 10 多种提取算法，Templates 提供 80 多个零代码领域模板。
- 用户可通过 CLI 命令完成完整工作流：he parse 解析文档、he search 语义搜索知识库、he show 可视化图谱、he export 导出 Obsidian
  笔记库。
- Hyper-Extract 支持通过 he-mcp（MCP Server）将知识摘要暴露给 Claude Desktop 和 IDE 代理，提供 list_templates、search、ask（RAG）等工具方法。
- 该工具兼容多家 LLM 提供商（OpenAI、Anthropic、阿里云百炼）和本地部署方案（vLLM + Qwen3.5-9B），通过 JSON Schema
  或 Function Calling 实现结构化输出。
- Hyper-Extract 在功能对比中覆盖了 GraphRAG、LightRAG、KG-Gen、ATOM 等现有方案不支持的时空图、超图、领域模板和交互式 CLI
  等能力。

Hyper-Extract is an intelligent, LLM-powered knowledge extraction and evolution framework. It radically simplifies transforming highly unstructured texts into persistent, predictable, and strongly-typed **Knowledge Abstracts**. It effortlessly extracts information into a wide spectrum of formats—ranging from simple **Collections** (Lists/Sets) and **Pydantic Models**, to complex **Knowledge Graphs**, **Hypergraphs**, and even **Spatio-Temporal Graphs**.

Feed a 20-page academic paper, get an interactive graph of key concepts, authors, and citations.

```
he parse paper.pdf -t general/academic_graph -o ./paper_kb/
he show ./paper_kb/
```

Automatically identify companies, executives, financial metrics, and their relationships from unstructured reports.

```
he parse earnings.md -t finance/earnings_graph -o ./finance_kb/
he search ./finance_kb/ "What are the key risk factors?"
```

**Auto-Types**— 8 strongly-typed data structures (Model, List, Set, Graph, Hypergraph, Temporal Graph, Spatial Graph, Spatio-Temporal Graph)**Methods**— Extraction algorithms: KG-Gen, GraphRAG, LightRAG, Hyper-RAG, Cog-RAG, and more**Templates**— 80+ presets across 6 domains. Zero-code setup.
