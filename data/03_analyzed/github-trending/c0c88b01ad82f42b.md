description: 'F´ - A flight software and embedded systems frameworkA Flight-Proven,
  Multi-Platform, Open-Source Flight Software Framework F´ (F Prime) is a component-driven
  framework that enables rapid development and deployment of spaceflight and other
  embedded software applications. Originally developed at the Jet Propulsion Laboratory,
  F´ has been successfully deployed on several space applications. It is tailored
  but not limited to small-scale spaceflight systems such as CubeSats, SmallSats,
  and instruments. Please Visit the F´ Website: https://fprime.jpl.nasa.gov for more
  information. What does F´ provide An architecture that decomposes flight software
  into discrete components with well-defined interfaces A C++ framework that provides
  core capabilities such as message queues and threads Modeling tools for specifying
  components and connections and automatically generating code A growing collection
  of ready-to-use components Testing tools for testing flight software at the unit
  and integration levels. Learn more about F´ key features. System Requirements The
  following system requirements apply to your workstation for developing F´ applications.
  To see the list of supported platforms on which F´ applications can run on, see
  Supported Platforms. Linux, Windows with WSL, or macOS operating system git Python
  3.10+, virtual environments, and PIP Clang or GNU C and C++ compilers (e.g. gcc
  and g++) Click to Expand: How to Verify System Requirements git --version python
  --version and python -m venv -h. Your system might use an alternate like python3
  or python3.13. For pip: pip --version. On your system it might be pip3 or pipx.
  g++ --version and then create, build, and run a test program. For example, create

tech_assessment:
  architecture_highlights: F´ 采用组件驱动（component-driven）架构，将飞行软件拆解为具有明确定义接口的离散组件。架构分为三层：1）C++
    运行时框架层——提供消息队列、线程管理、端口通信等核心基础设施，组件间通过端口（ports）进行类型安全的异步/同步通信；2）建模工具层——通过 FPP（F
    Prime Prime）领域特定语言对组件、拓扑和连接关系进行声明式建模，并自动生成 C++ 骨架代码，大幅降低手写样板代码量；3）测试工具层——内置单元测试和集成测试框架，支持在桌面环境模拟运行飞行软件。这种分层解耦设计使得开发者可以专注于组件业务逻辑，同时保持关键任务系统所必需的可追溯性和确定性行为。
  tech_stack_quality: production_grade
  code_quality_indicators:
    has_tests: true
    has_ci_cd: true
    documentation_level: comprehensive
  dependencies_analysis: 核心依赖栈精炼且自洽：运行时仅依赖标准 C++ 编译工具链（gcc/clang）和 POSIX 系统调用，无重型第三方库耦合。工具链层依赖
    Python 生态，包括 fprime-bootstrap（项目脚手架 CLI）、fprime-gds（地面数据系统 GUI，基于 Python/Tkinter）和
    fpp（F´ 建模语言编译器）。平台支持 Linux、macOS 和 Windows WSL。整体依赖耦合度低，核心框架的嵌入式运行时可以独立于工具链使用，但在实际开发流程中高度绑定
    FPP 建模工具和自动代码生成管线，形成一定的工具链锁定效应。

F´ (F Prime) is a component-driven framework that enables rapid development and deployment of spaceflight and other embedded software applications. Originally developed at the Jet Propulsion Laboratory, F´ has been successfully deployed on several space applications. It is tailored but not limited to small-scale spaceflight systems such as CubeSats, SmallSats, and instruments.

**Please Visit the F´ Website:** https://fprime.jpl.nasa.gov for more information.

- An architecture that decomposes flight software into discrete components with well-defined interfaces
- A C++ framework that provides core capabilities such as message queues and threads
- Modeling tools for specifying components and connections and automatically generating code
- A growing collection of ready-to-use components
- Testing tools for testing flight software at the unit and integration levels.

Learn more about F´ key features.

The following system requirements apply to your workstation for developing F´ applications. To see the list of supported platforms on which F´ applications can run on, see Supported Platforms.

-
Linux, Windows with WSL, or macOS operating system

-
Clang or GNU C and C++ compilers (e.g. gcc and g++)

```
pip install fprime-bootstrap
```


Then, create a new project with:

```
fprime-bootstrap project
```
