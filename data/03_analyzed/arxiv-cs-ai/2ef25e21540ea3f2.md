description: 'arXiv:2607.02931v1 Announce Type: new Abstract: AI tools are accelerating
  scientific publication while the systems that review it struggle to keep up, and
  independent verification of published research has become both harder and more important.
  As manual replication is slow and expensive, a growing line of work uses coding
  agents to automate parts of the process. Existing efforts are largely packaged as
  benchmarks with companion agents that only run inside the benchmark''s own pipeline,
  and no general-purpose replication tool exists. We present VERITAS, a domain-agnostic
  replication framework built around CLI coding agents. Given a paper, a code repository,
  or both, VERITAS extracts the paper''s claims, runs the methodology while resolving
  issues as they arise, and judges each claim against the evidence from experiment
  runs. The pipeline returns an importance-weighted Replication Score, a severity-rated
  log of every fix applied, and the patched codebase. We evaluate VERITAS on CORE-Bench
  and ReplicationBench, 65 papers spanning computer science, social science, medicine,
  and astrophysics. Against two strong Claude Code baselines on the same model and
  host environment, VERITAS achieves state-of-the-art performance and leads on every
  metric on both benchmarks.'

research_problem:
  core_question: 能否构建一个领域无关的通用自动化论文复现工具，以独立验证已发表研究的可复现性？
  motivation: AI工具正在加速科研成果的发表，但同行评审系统难以跟上这一节奏，对已发表研究的独立验证变得既更重要也更加困难。传统的人工复现方法耗时且昂贵，而现有的基于编码智能体的自动化复现工作主要集中在构建评测基准及其配套智能体上，这些智能体仅能在各自基准的封闭管道中运行，缺乏通用性。当前亟需一个不依赖特定领域的通用复现工具来规模化地验证研究声明的可信度。
  significance: practical
  gap_addressed: 现有论文复现工具/智能体均为特定评测基准（如 CORE-Bench、ReplicationBench）设计的配套系统，仅能在各自基准内部运行，不存在一个领域无关的通用复现工具。VERITAS
    填补了这一空白，提供了一个可跨计算机科学、社会科学、医学和天体物理学的通用复现框架。
methodology:
  approach_summary: VERITAS 是一个围绕 CLI 编码智能体构建的领域无关复现框架。给定一篇论文、一个代码仓库或两者兼有，VERITAS
    首先从论文中提取可验证的研究声明，然后运行论文方法并在执行过程中自动解决出现的各类问题（如依赖缺失、配置错误、环境不一致等），最后根据实验运行得到的证据逐条判断每个声明的成立与否。管道输出三个核心结果：一个带重要性权重的复现评分（Replication
    Score）、一个按严重程度分类的所有修复操作的日志，以及最终修补后的完整代码库。该方法将复现过程解构为声明提取→执行复现→证据判断三个自动化阶段，利用 LLM
    编码智能体的能力在真实环境中自主操作。

  - 构建了按严重程度分类的修复日志系统，系统记录所有在复现过程中对实验代码做出的修补操作，提升了复现过程的透明度和可审计性

# Title:VERITAS: Towards a General-Purpose Replication Tool for Scientific Research

View PDF HTML (experimental)Abstract:AI tools are accelerating scientific publication while the systems that review it struggle to keep up, and independent verification of published research has become both harder and more important. As manual replication is slow and expensive, a growing line of work uses coding agents to automate parts of the process. Existing efforts are largely packaged as benchmarks with companion agents that only run inside the benchmark's own pipeline, and no general-purpose replication tool exists. We present VERITAS, a domain-agnostic replication framework built around CLI coding agents. Given a paper, a code repository, or both, VERITAS extracts the paper's claims, runs the methodology while resolving issues as they arise, and judges each claim against the evidence from experiment runs. The pipeline returns an importance-weighted Replication Score, a severity-rated log of every fix applied, and the patched codebase. We evaluate VERITAS on CORE-Bench and ReplicationBench, 65 papers spanning computer science, social science, medicine, and astrophysics. Against two strong Claude Code baselines on the same model and host environment, VERITAS achieves state-of-the-art performance and leads on every metric on both benchmarks.
