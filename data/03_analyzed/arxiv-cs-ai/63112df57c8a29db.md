description: 'arXiv:2606.30911v1 Announce Type: new Abstract: ML engineering agents
  waste compute rediscovering known techniques because every competition is a cold
  start. We present HASTE, a hierarchical multi-agent system that organizes cross-competition
  knowledge into three scope tiers (global, domain, and competition-specific), each
  coupled to a matching agent level. An orchestrator coordinates domain specialists
  and promotes learning between tiers via LLM-driven abstraction. A controlled ablation
  provides evidence for scoped loading: holding a 159-skill inventory constant across
  8 competitions, tiered loading achieves a 100% medal rate while flat loading reaches
  only 62.5%, the same medal rate as loading no skills, and consumes 2x the output
  tokens. On the full MLE-Bench Lite benchmark (22 Kaggle competitions), HASTE reaches
  a medal rate of 77.3% using Claude Sonnet 4.6 at 12h per competition. In a cold-start
  run, the system begins with no accumulated skills. In warm-start runs, it reloads
  skills learned from earlier competitions, using only global and domain-level skills
  for transfer across competitions. Warm starts use 52% fewer refinement iterations,
  and the fraction of proposed changes kept by the agent rises from 42% at low inventory
  to 85% once 50+ skills are available. These results suggest that better knowledge
  organization can partly substitute for model strength and compute budget in ML-engineering
  agents.'

research_problem:
  core_question: 如何通过层次化的知识组织方式，让 ML 工程智能体跨任务高效复用技能，避免每次从零开始？
  motivation: 现有的 ML 工程智能体（如参与 Kaggle 竞赛的 AI agent）在每项新任务上都是从零开始，浪费大量计算资源重复发现已知技术。随着
    ML 工程任务日益复杂，知识的高效迁移与复用成为提升智能体效率和降低成本的关键瓶颈。
  significance: practical
  gap_addressed: 现有 ML 工程智能体缺乏结构化的跨任务知识迁移机制，知识通常以扁平方式存储或完全不做复用；本文提出了首个层次化技能积累框架，将知识按作用范围分为全局、领域、竞赛特定三级，并匹配合适的智能体层级进行加载，填补了结构化技能迁移在
    ML 工程 agent 中的空白。
methodology:
  approach_summary: HASTE 是一个层次化多智能体系统，将跨竞赛的知识技能组织为三个作用范围层级：全局级（通用 ML 工程最佳实践）、领域级（特定领域如
    NLP/CV 的专门技术）和竞赛特定级。每个层级对应特定级别的智能体角色，由编排器（orchestrator）协调领域专家，通过 LLM 驱动的抽象机制在层级之间进行技能提炼与提升。在运行新竞赛时，系统根据任务范围选择性加载对应层级的技能（即
    scoped loading），而非将所有技能扁平加载。
  novelty_type: architectural
  key_innovations:
  - 提出三级层次化技能组织架构（Global → Domain → Competition-specific），与智能体层级一一对应，实现作用范围与执行粒度的精准匹配
  - 引入 Scoped Loading 机制，在保持技能总量不变的条件下，仅加载与当前任务范围匹配的技能层级，显著降低 token 消耗并提升决策质量
  - 设计 LLM 驱动的跨层级技能抽象机制（abstraction），允许将竞赛特定经验提炼为领域级乃至全局级通用技能，实现知识的高效自举与泛化

# Title:Why Solve It Twice? Hierarchical Accumulation of Skills for Transfer-Efficient ML Engineering

View PDF HTML (experimental)Abstract:ML engineering agents waste compute rediscovering known techniques because every competition is a cold start. We present HASTE, a hierarchical multi-agent system that organizes cross-competition knowledge into three scope tiers (global, domain, and competition-specific), each coupled to a matching agent level. An orchestrator coordinates domain specialists and promotes learning between tiers via LLM-driven abstraction. A controlled ablation provides evidence for scoped loading: holding a 159-skill inventory constant across 8 competitions, tiered loading achieves a 100% medal rate while flat loading reaches only 62.5%, the same medal rate as loading no skills, and consumes 2x the output tokens. On the full MLE-Bench Lite benchmark (22 Kaggle competitions), HASTE reaches a medal rate of 77.3% using Claude Sonnet 4.6 at 12h per competition. In a cold-start run, the system begins with no accumulated skills. In warm-start runs, it reloads skills learned from earlier competitions, using only global and domain-level skills for transfer across competitions. Warm starts use 52% fewer refinement iterations, and the fraction of proposed changes kept by the agent rises from 42% at low inventory to 85% once 50+ skills are available. These results suggest that better knowledge organization can partly substitute for model strength and compute budget in ML-engineering agents.
