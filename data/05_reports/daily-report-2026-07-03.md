**背景**: 随着单芯片制程逼近物理极限，AI 算力增长的核心矛盾已从'造更大的芯片'转向'如何高效连接芯片集群'。WAIC 2026 集中发布了华为 Atlas 950 SuperPoD（单柜 64 卡/最大 8192 卡）、中兴 OEX+dOCS Matrix 超节点等多芯协同方案，以及曦智科技港股上市标志的光互连产业化里程碑。集群线性度每提升 10 个百分点可降低硬件成本 15%、节省电费 20%的经济推论，正驱动算力竞争从单卡峰值竞赛全面转向系统级架构创新。FlagOS 联合 Linux、Eclipse、PyTorch 三大国际开源基金会，试图以开源协作解决'一卡一软件'的算力碎片化问题。

**影响**: 这一转变将重塑 AI 基础设施的投入结构和竞争格局。短期看，万卡级训练集群的采购决策将从'选哪家 GPU'变为'选哪套系统方案'，华为、中兴以系统级产品直接挑战 NVIDIA 的 NVLink+CUDA 生态；长期看，光互连技术的产业化将催生数百亿美元的新增市场，从光模块、硅光芯片到光电混合计算，形成完整的国产替代产业链。FlagOS 若成功推动统一软件栈，将大幅降低国产芯片的软件迁移成本，加速多元算力生态从碎片化走向收敛。对于投资决策而言，系统级算力优化服务、光互连供应链、以及跨芯片架构的中间件工具将成为确定性最高的增量市场。

**后续关注**: 需重点关注三个指标：华为 Atlas 950 SuperPoD 的实际集群线性度是否达到宣传水平（对比 NVIDIA NVLink 的实测数据）、曦智科技上市后首个季度的产品交付进度与客户采纳情况、FlagOS 能否在 2026 年底前吸引至少 3 家芯片厂商完成适配。若三项指标均符合预期，系统级算力方案将在 2027 年进入规模化部署阶段，届时 NVIDIA 在中国 AI 训练市场的份额可能首次出现实质性下降。反之，若软件生态碎片化无法解决，国产超节点方案可能陷入'硬件领先、软件落后'的困境。

**影响**: 跨模型互操作将根本性改变开发者的工具选择逻辑——不再需要在 Claude Code 和 Codex 之间做排他性选择，而是按任务类型动态组合最优模型。这降低了平台锁定的风险，但也意味着单一模型优势不再是护城河——生态整合深度和互操作协议的掌控力才是新的竞争维度。对创业公司而言，多模型编排中间件、Agent 会话迁移协议、跨平台审查门禁成为新兴蓝海赛道。对大型企业，这意味着可以构建'模型冗余架构'以规避单供应商中断风险，呼应了 Fable 5/GPT-5.6 发布受限所暴露的供应不稳定性。Agent Skills 标准若获得跨平台采纳，将催生类似 Docker Hub 的 Agent 技能市场，Anthropic 有望通过标准制定占据生态位——这是继 MCP 之后的又一关键布局。
