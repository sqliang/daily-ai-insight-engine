## Critical (4)

### [C-1] `_CONFIDENCE_FUZZY` 字典含重复 key，导致 LLM 置信度静默映射错误

- **文件**: `pipeline/analysis/deep_analysis_agent.py:227-229`
- **维度**: 代码质量与 Bug
- **描述**: `_CONFIDENCE_FUZZY` 字典中 `"uncertain"` 作为 key 出现了两次（line 227 映射为 `"medium"`，line 229 映射为 `"low"`）。Python 静默保留最后一个值 (`"low"`)，导致 LLM 返回 `"uncertain"` 的语义（中等置信度）被错误映射为低置信度，所有基于置信度的分析结果可能系统性偏低。
- **代码**:
  ```python
  "uncertain": "medium",
  "low": "low",
  "uncertain": "low",   # ← 重复 key，覆盖上一行
  ```
- **建议**: 删除 line 229 的重复项，保留 `"uncertain": "medium"`（语义上 "不确定" 对应中等置信度更合理）。

### [C-2] `MetricCard.tsx` — `requestAnimationFrame` 泄漏：无清理函数

- **文件**: `src/components/dashboard/MetricCard.tsx:20-40`
- **维度**: 代码质量与 Bug
- **描述**: `useEffect` 中启动 `requestAnimationFrame` 循环，但未返回清理函数。组件卸载后动画继续执行，`setDisplayValue` 在已卸载组件上调用。同时 `animated.current` ref 阻止 value prop 变化后重新动画，数字卡片展示值不再更新。
- **代码**:
  ```tsx
  useEffect(() => {
      if (animated.current) return;
      animated.current = true;
      const animate = (timestamp: number) => {
          setDisplayValue(Math.round(eased * numValue).toString());
          if (progress < 1) requestAnimationFrame(animate);
      };
      requestAnimationFrame(animate);
      // ← 缺少 return () => cancelAnimationFrame(rafId)
  }, [value]);
  ```
- **建议**: 保存 `rafId` 并在清理函数中 `cancelAnimationFrame(rafId)`。

### [C-3] `scout/orchestrator.py` — 手动调用 `BrowserSession.__exit__(None,None,None)` 抑制所有异常

- **文件**: `pipeline/ingestion/scout/orchestrator.py:124-125`
- **维度**: 代码质量与 Bug
- **描述**: `finally` 块中调用 `browser_session.__exit__(None, None, None)`，三个 `None` 参数告诉 Python 抑制 `__enter__` 期间的所有异常（包括 `KeyboardInterrupt`、`SystemExit`）。且 `__enter__` 在 `try` 块之外执行，逻辑不一致。浏览器进程清理失败时异常被静默吞掉。
- **建议**: 使用 `ExitStack`（与 `ingest/orchestrator.py` 保持一致）或标准 `with browser_session:` 上下文管理器。

### [C-4] `frontmatter_utils.py` — `source_name` 参数被接受但从未使用，文章来源信息丢失

- **文件**: `pipeline/core/frontmatter_utils.py:13-54`
- **维度**: 代码质量与 Bug
- **描述**: `build_ingestion_frontmatter()` 接受 `source_name: str = ""` 参数，但函数体中从未将其写入返回的 frontmatter dict。两个调用方（`worker.py:97` 和 `worker.py:199`）都传入了 `source_name`，期望它被持久化。下游阶段无法从 frontmatter 中确定文章来源。
- **建议**: 在返回的 frontmatter dict 中添加 `"source_name": source_name`。

- **建议**: 在 `proxy.json` 和 `setup_proxy()` 中添加 `no_proxy` 支持。

### [L-4] `enum_utils.py` — 过宽的子串匹配

- **文件**: `pipeline/utils/enum_utils.py:38`
- **维度**: 代码质量与 Bug
- **描述**: `k in key or key in k` 子串匹配可能产生误报。例如 mapping 中有 `{"e": "excited"}` 且 value 为 `"neutral"` 时，`"e" in "neutral"` 为 True。
- **建议**: 仅对长度 >= 4 的 mapping key 执行子串匹配，或使用编辑距离算法。

### [L-5] `RadarChart.tsx` — 缺少 `domain` prop，缩放不一致

### [L-8] `heuristics.ts` — 每个调用创建 RegExp 对象
