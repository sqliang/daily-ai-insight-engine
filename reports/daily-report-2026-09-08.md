### AI 自动形式化与数学研究范式迁移

**背景**: 2024 年 Kevin Buzzard 发起用 Lean 形式化费马大定理的多年期社区项目，官方预计耗时数年；而 Anthropic 宣布 Claude 以 11 天近乎自主地产出端到端机器可检查证明，并获 Buzzard 认可。同期，Buckmaster 团队借助 LLM 将受迫爆破构造推进到光滑外力并扩展至三维欧拉方程，首个 LLM 生成证明于 8 月 22 日通过 Lean 验证。

**影响**: 这标志着 AI 从辅助计算、猜猜想跃升到生成可机器验证的新定理，证明的创造性部分首次可被模型承担、由人审计，其长期复利在于可验证证明能反哺强化学习与合成数据。同时，OpenAI 与 Anthropic 围绕成果署名与发表时序的争端，正在重塑学界与实验室的合作规则、数据归属与利益冲突界定。

**后续关注**: 需跟踪三项已公开爆破结果的同行评审与欠耗散纳维-斯托克斯的 Lean 验证进展、OpenAI 与 Anthropic 的成果归属争端如何落地，以及自动形式化能力向芯片、密码学、软件验证等工程领域的商业化外溢速度。

### 递归自我改进与智能体驱动的研发闭环

**背景**: OpenAI 首次公开量化智能体参与自身研发的数据：研究员每投入一个人工作日即伴随 3.1 个智能体工作日，中位研究者每日 API 推理费用超 600 美元，并如期达成去年秋季设定的自动化研究实习生里程碑，预告 2028 年 3 月建成自动化 AI 研究员。

**影响**: 这形成用更好的模型造更好的模型的自举飞轮，把推理成本内化为核心研发开支，显著强化头部实验室的复利壁垒并抬高行业进入门槛。首席科学家 Pachocki 同日警告对齐与监控研究尚未跟上，思维链监控窗口可能随模型增强而收窄，为扩张路径埋下真实的治理与安全下行风险。

**后续关注**: 需监测其他实验室是否跟进披露同类研发效率数据、超半数 4 至 8 小时任务仍需人工干预这一瓶颈的改善速度，以及监管对递归自我改进、算力扩张与安全披露义务的态度变化。

### Agent 基础设施开源浪潮

**背景**: 今日开源生态密集释放 Agent 基础设施信号：Lightpanda 以 Zig 从零实现无头浏览器，宣称内存与耗时约为 Chrome 的 1/16 与 1/9；DeerFlow 2.0 登顶 GitHub Trending；Salesforce 开源无信号 KV cache 驱逐策略 Random Attention；微软、HeyGen、Terrastruct 分别开源文档转换、确定性视频渲染与布局引擎。

**影响**: 这批项目共同瞄准 AI Agent 规模化落地的两个瓶颈——浏览器运行时的资源成本与推理服务的内存开销，以及智能体生成内容与文档的可复现性。基础设施层正从商业服务向开源标准沉降，将压缩浏览器云、文档解析服务与学习式 KV 压缩方案的溢价空间，并推动确定性契约与协议兼容成为默认设计。

**后续关注**: 关注各项目的第三方基准复现与真实采用率、Lightpanda 对 V8 与复杂站点的兼容性边界、DeerFlow 与字节生态绑定程度，以及云厂商与平台方是否会将这些能力内置化从而挤压独立项目的生存空间。
